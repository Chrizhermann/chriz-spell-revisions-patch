# Spell Revisions — Chriz Balance Patch v4.21-chriz.5

Adds two optional Lightning Bolt behaviors while retaining all previous fixes and
the separate Rogue Rebalancing compatibility package.

- **Classic bouncing (component 80):** wizard Lightning Bolt hits creatures along
  its path, bounces from walls, can hit allies and the caster, and uses a Spell save
  for half damage. Mirror Image does not absorb the area damage. Wands are unchanged.
- **Non-bouncing spell and wands (81):** the same restored wizard damage rules, but
  no bouncing. Direct lightning wands also use the private non-bouncing projectile;
  dedicated traps keep the original projectile. Supported projectile protections
  are cloned for the new projectile.
- **Keep Spell Revisions:** skip both alternatives. Components 80 and 81 are mutually
  exclusive, require SR component 0, and cannot be combined with CD Tweaks 2530.

CEBG's curated default is classic bouncing. Standalone users choose their preference.
Install the selected alternative after other spell changes. Damage remains capped
at 10d6, later save penalties and SCS casting features are retained, and unrelated
spell and wand properties are preserved. Detailed scope and limitations are in the
Lightning component README; this is not a rewrite of every mod-added lightning copy.

## Windows downloads

- `spell_rev-v4-21-chriz-5.zip`: full SR fork, plus the SR/RR compatibility and
  Lightning tail mini-mods and all three Windows setup executables.
- `SRCB_RR_COMPAT-v4-21-chriz-5.zip`: compatibility-only package; behavior is unchanged
  from v4.21-chriz.4. Install component 0 after SR and RR 11 and/or 12.
- `SRCB_CLASSIC_LIGHTNING-v4-21-chriz-5.zip`: Lightning-only tail package; component 0
  is classic bouncing and component 1 is non-bouncing spell/wands. Do not install
  both a main-fork alternative and its tail equivalent.

Every archive contains WeiDU 249 x64, its license and manual. Main-fork and both
standalone TP2s report v4.21-chriz.5. Close the game before installing anything.
These packages do not implement automatic CEBG hotpatching. Existing saves can
retain active effects and already-spawned creatures; the RR migration does not
rewrite creatures embedded in saves. Do not reinstall SR mid-stack merely to update.

## Verification and provenance

110 automated tests passed with real WeiDU 249, including 39 Lightning tests:
real SR source spells, relocated resources, preservation of extra effects and
casting features, damage/save semantics, both projectile layouts, selective wands,
protection cloning, exclusivity, rejected unsupported inputs, and byte-exact resource
restoration on uninstall. All existing SR/RR and NPC-spellbook tests remain green.

The gameplay libraries are restored without changes from the previously rehearsed
snapshot `29538896e4d9f2836833f5d925b90f7fe181c69c`, on top of v4.21-chriz.4. The
maintainer requested integration now and runtime casting tests in the full CEBG
installation afterwards. No live installation or save was changed for this release.
