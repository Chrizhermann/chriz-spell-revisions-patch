# Spell Revisions — Chriz Balance Patch v4.21-chriz.6

Corrects the Rogue Rebalancing compatibility after a BG2:EE 2.7.3.0 lab check. The RR
compatibility and the Lightning Bolt options now recognize what they patch by meaning,
so other copy counts, extra script branches and damage added by other mods no longer
stop them. Spell Revisions' main component, component 60 and the component menu are
unchanged.

- **Rogue Rebalancing compatibility (`SRCB_RR_COMPAT` 0):** Chaos stays SR's level-7
  spell. RR v4.92's prepared level-5 Chaos copies become a level-5 spell where they
  stand, keeping their flags and every spell-slot cap: Hold Monster for Aran Linvail,
  Feeblemind for the Zhentarim Mercenary and Domination for Selina. This replaces the
  level-7 migration of v4.21-chriz.4 and .5: Aran and the Mercenary could never cast
  the moved copies, which sat behind their level-7 slot counters.
- **Spellbooks:** Selina is a sorcerer and casts from her known list, so her known
  old-slot record becomes Domination too, without a duplicate if she already knows it.
  Wizards keep their known records. `RR#SAW09` and `RR#ZAER` only know the old slot and
  are no longer changed.
- **Scripts:** all three RR scripts cast the replacement in either SR/RR order. Blocks
  that pick a target keep their filters and gain the checks the replacement needs,
  written as RR's own blocks check them: Spell Turning and similar protections for
  Feeblemind and Domination, charm-protection items for Domination, and free action and
  hold-immune kits and items for Hold Monster. Selina's opening Spell Trigger casts
  Domination; her Spell Deflection guard from v4.21-chriz.4 is kept.
- **Recognition:** spellbook entries and script references are recognized by the spell
  they name, not by the audited copy and reference counts, and hexadecimal `SPELL.IDS`
  values are read. A creature or script naming both RR's old slot and SR's Chaos, or
  holding the old slot outside the level-5 wizard book, fails with the resource named
  instead of being guessed at.
- **Lightning Bolt options (80, 81; `SRCB_CLASSIC_LIGHTNING` 0, 1):** SR's two damage
  halves are identified by meaning, in either order. Damage another mod adds to the
  bolt, such as a fire rider, is kept instead of failing the installation, and a repeat
  application is byte-exact. Several effects matching one half still fail as ambiguous.

## Windows downloads

- `spell_rev-v4-21-chriz-6.zip`: full SR fork, plus the SR/RR compatibility and
  Lightning tail mini-mods and all three Windows setup executables.
- `SRCB_RR_COMPAT-v4-21-chriz-6.zip`: compatibility-only package. Install component 0
  after SR and RR 11 and/or 12.
- `SRCB_CLASSIC_LIGHTNING-v4-21-chriz-6.zip`: Lightning-only tail package; component 0
  is classic bouncing and component 1 is non-bouncing spell/wands. Do not install
  both a main-fork alternative and its tail equivalent.

Every archive contains WeiDU 249 x64, its license and manual. Main-fork and both
standalone TP2s report v4.21-chriz.6. Close the game before installing anything.
These packages do not implement automatic CEBG hotpatching. An installed
`SRCB_RR_COMPAT` can be updated in place only while it is the last entry in WeiDU.log:
replace its folder and setup executable and reinstall component 0, and WeiDU restores
the previous version's backup first. Deeper in a stack, do not reinstall it: WeiDU 249
either skips it or reinstalls every later component, which can drop some of them. The
component changes game resources, not creatures already embedded in a save, so install
it before the affected encounters are first entered. Do not reinstall SR mid-stack
merely to update.

## Verification and provenance

198 automated tests passed with real WeiDU 249, including 53 SR/RR compatibility
tests: both install orders converge byte-exactly and a second pass is byte-exact; a
sorcerer's known and memorized records change together without duplicates while
wizards keep theirs; other copy counts, flags, classes and spellbook layouts are
handled; added checks appear once; ambiguous or malformed shapes fail; and uninstall
restores the resources. The 88 Lightning Bolt tests add foreign damage, reordered
halves, ambiguous damage and repeat application to the v4.21-chriz.5 checks.

A local check applied the RR component to RR v4.92's own five creatures and three
scripts in both orders, against a 2.7.3.0 installation's final IDS and SR spell files.
The level-5 spellbooks are exactly the approved replacements, `RR#SAW09` and `RR#ZAER`
stay unchanged, and the script changes stay inside the Chaos blocks. Installed over
the v4.21-chriz.5 component as the last WeiDU.log entry, it gave the same resources
as a fresh install. The level-5
replacements have not been checked in game yet; full hostile encounters and a wider
SCS audit remain untested. No live installation or save was changed for this release.
