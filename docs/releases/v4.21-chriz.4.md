# Spell Revisions — Chriz Balance Patch v4.21-chriz.4

Adds a small, late-installable compatibility component for Rogue Rebalancing
v4.92 and Spell Revisions:

- Restores the intended Chaos in five RR mage spellbooks and three AI scripts,
  including their forced-cast opening sequences. Copy counts and spell-slot caps
  are preserved.
- Corrects Selina's Spell Turning self-recast guard to recognize SR's Spell
  Deflection state, without changing her cast identifier or tactics.
- Accepts either SR/RR base install order, is idempotent, and rejects unexpected
  resource shapes. The main SR spell gameplay and component menu are unchanged.

## Downloads and install order

- **`spell_rev-v4-21-chriz-4.zip`**: full SR fork, plus the separate
  `SRCB_RR_COMPAT` component. Includes both Windows installers.
- **`SRCB_RR_COMPAT-v4-21-chriz-4.zip`**: compatibility component only, for an
  existing SR/RR installation. There is no need to reinstall SR.

Both archives include [official WeiDU 249 x64](https://github.com/WeiDUorg/weidu/releases/tag/v249.00),
its license, and its manual. The main and compatibility TP2s
report `v4.21-chriz.4` in WeiDU.log.

Install `SRCB_RR_COMPAT` component 0 **after both SR's main component and RR's
Chosen of Cyric (11) and/or Shadow Thief Improvements (12)**. SR before RR is the
preferred base order. Running the main SR installer does not install this extra
component. Apply it before the affected creatures are spawned/saved; it does not
rewrite creatures already embedded in a save.

## Verification

71 automated tests passed with real WeiDU 249, covering both install orders,
spellbook/slot preservation, IDS aliases, prerequisite scoping, rejected malformed
inputs, idempotence, and uninstall restoration. Authentic RR/SR installer checks
also passed in both orders. The user reported a successful quick in-game
spellbook/casting smoke test on an isolated BG2:EE 2.6.6.0 installation.

Full hostile-encounter testing and a wider SCS compatibility audit remain deferred.
Blindness, Deafness, Bigby's spells, and Infravision are not changed. The separate
Death Ward handover is documentation only, not an implemented release feature.
